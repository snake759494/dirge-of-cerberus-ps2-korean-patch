# PCSX2 16:9 와이드 패치

한글 패치는 실행 파일(SLPM_666.29)의 문구를 수정하므로 게임 CRC가 원본 **BC06733B**에서 **093E5F56**으로 바뀝니다. PCSX2 내장 와이드 패치는 CRC로 파일을 찾기 때문에 한글판에는 자동 적용되지 않습니다. 그래서 내장 패치를 내용 그대로 한글판 CRC용으로 옮긴 `SLPM-66629_093E5F56.pnach`를 제공합니다. 패치가 고치는 3개 주소(0x40C5F8, 0x40C5FC, 0x40D1F0)는 한글판에서도 원본과 바이트가 같음을 확인했습니다.

## PCSX2 2.x (권장)

1. `SLPM-66629_093E5F56.pnach`를 `문서\PCSX2\patches\` 폴더에 넣습니다(포터블 설치는 `PCSX2 폴더\patches\`).
2. 게임 목록에서 한글판 ISO를 오른쪽 클릭 → **속성** → **패치** 탭 → **Widescreen 16:9** 체크.
   - 목록에 보이지 않으면 한 번 게임을 실행했다 끄면 나타납니다.
3. 속성 → **그래픽** → 디스플레이에서 화면 비율을 **16:9** 로 둡니다(패치에 `gsaspectratio=16:9` 가 들어 있어 보통 자동).
   동영상(FMV)은 원래 4:3이므로 **FMV 화면 비율 전환**은 **4:3** 을 권장합니다.
4. 게임 시작 시 화면 위쪽에 “1개의 게임 패치가 활성화되었습니다” 알림이 뜨면 적용된 것입니다.

설정 파일로 켜려면 `문서\PCSX2\gamesettings\SLPM-66629_093E5F56.ini` 에 다음을 저장합니다.

```ini
[EmuCore]
EnableWideScreenPatches = true

[Patches]
Enable = Widescreen 16:9

[EmuCore/GS]
AspectRatio = 16:9
FMVAspectRatioSwitch = 4:3
```

## PCSX2 1.6

파일 이름을 `093E5F56.pnach` 로 바꿔 `cheats_ws` 폴더에 넣고, **시스템 → 와이드스크린 패치 사용**을 켠 뒤 **비디오(GS) → 창 설정**에서 화면 비율 16:9 를 고릅니다.

## 참고

- 끄려면 패치 탭의 체크를 해제합니다.
- 원본(일본어) ISO에는 PCSX2 내장 패치(`SLPM-66629_BC06733B`)가 그대로 적용됩니다.
- 이 패치는 3D 화면 비율만 바꿉니다. 메뉴·HUD 등 2D 화면은 일부 가로로 늘어나 보일 수 있습니다.
- 확인 범위: PCSX2 2.2에서 패치 활성화 로그와 첫 전투 장면의 16:9 표시. 컷신·메뉴 전 구간은 미확인.
